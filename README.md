
<h1>Política de Privacidad</h1>
<p class="fecha">Dr. Reminder — Última actualización: 12/08/2026</p>

<p>Esta Política de Privacidad describe cómo <strong>Shell Core Software</strong>
 gestiona la información que los usuarios introducen y utilizan dentro de
<strong>Dr Reminder</strong>.</p>

<h2>1. Responsable de la aplicación</h2>
<p>
<strong>Shell Core Software</strong><br>
Correo de contacto: <a href="mailto:shellcoresoftware8@gmail.com">shellcoresoftware8@gmail.com</a>
</p>

<h2>2. Información que puede introducir el usuario</h2>

<p><strong>a) Datos del perfil:</strong></p>
<ul>
  <li>Nombre de la persona registrada en la App</li>
  <li>Edad</li>
  <li>Número de teléfono, cuando el usuario decide proporcionarlo</li>
  <li>Correo electrónico, cuando el usuario decide proporcionarlo</li>
</ul>

<p><strong>b) Información relacionada con medicamentos:</strong></p>
<ul>
  <li>Nombre del medicamento</li>
  <li>Dosis o cantidad por toma</li>
  <li>Cantidad disponible</li>
  <li>Horarios de administración</li>
  <li>Frecuencia de los recordatorios</li>
  <li>Fecha y hora de inicio de los recordatorios</li>
</ul>

<p><strong>c) Información de actividad física:</strong></p>
<ul>
  <li>Conteo de pasos diarios, cuando el usuario utiliza la función de actividad física de la App y concede el permiso correspondiente al dispositivo.</li>
</ul>

<p>El usuario decide qué información introducir y qué funciones utilizar dentro de la App.</p>

<h2>3. Dónde se almacenan tus datos</h2>

<p>Toda la información personal, del perfil, de medicamentos y demás información
introducida directamente en la App se almacena <strong>localmente en el propio
dispositivo del usuario</strong>, mediante el almacenamiento interno de la aplicación.</p>

<p>La App no requiere la creación de una cuenta en un servidor externo para utilizar
sus funciones principales y no envía deliberadamente la información introducida por
el usuario a servidores propios de Shell Core Software para almacenamiento remoto.</p>

<p>La información almacenada localmente se utiliza para que las funciones de la App
continúen funcionando, incluyendo los recordatorios y la información registrada por
el usuario.</p>

<h2>4. Uso de la información</h2>

<p>La información almacenada por la App se utiliza exclusivamente para proporcionar
las funciones solicitadas por el usuario, incluyendo:</p>

<ul>
  <li>Mostrar y gestionar el perfil registrado en la App</li>
  <li>Registrar y mostrar los medicamentos introducidos por el usuario</li>
  <li>Programar y gestionar recordatorios</li>
  <li>Actualizar y mostrar la cantidad disponible de medicamentos</li>
  <li>Mostrar avisos relacionados con la información registrada</li>
  <li>Mantener los recordatorios programados</li>
  <li>Mostrar información relacionada con la actividad física cuando el usuario utiliza dicha función</li>
</ul>

<p><strong>Shell Core Software no vende, alquila ni comercializa la información
introducida por los usuarios.</strong></p>

<h2>5. Compartición de datos con terceros</h2>

<p>La información personal y relacionada con medicamentos introducida por el usuario
se almacena localmente en su dispositivo y <strong>no se comparte deliberadamente con
terceros para fines de almacenamiento, publicidad o comercialización</strong>.</p>

<p>La App no utiliza deliberadamente la información personal o de medicamentos del
usuario para publicidad personalizada.</p>

<p>Si en futuras versiones de la App se incorporan servicios de terceros que recopilen
o procesen información del usuario, esta Política de Privacidad será actualizada para
reflejar dichos cambios.</p>

<h2>6. Permisos que solicita la App</h2>

<p>Dependiendo de la versión del sistema operativo y de las funciones utilizadas,
Dr. Reminder puede solicitar los siguientes permisos:</p>

<ul>
  <li><strong>Notificaciones:</strong> para mostrar los recordatorios de medicamentos.</li>
  <li><strong>Alarmas exactas:</strong> para programar los recordatorios en los horarios configurados por el usuario.</li>
  <li><strong>Actividad física:</strong> para obtener el conteo de pasos cuando el usuario utiliza las funciones relacionadas con actividad física.</li>
  <li><strong>Recepción de eventos después del reinicio:</strong> para restaurar y mantener los recordatorios programados después de reiniciar el dispositivo.</li>
</ul>

<p>Los permisos se utilizan únicamente para proporcionar las funciones
correspondientes de la App.</p>

<h2>7. Actividad física</h2>

<p>Cuando el usuario utiliza las funciones relacionadas con actividad física, la App
puede acceder a la información necesaria para obtener el conteo de pasos del
dispositivo, siempre que el usuario haya concedido el permiso correspondiente.</p>

<p>Esta información se utiliza para mostrar estadísticas o información de actividad
física dentro de la App y no se utiliza para realizar diagnósticos médicos,
determinar enfermedades ni establecer tratamientos.</p>

<h2>8. Menores de edad</h2>

<p>Dr. Reminder puede utilizarse para registrar información relacionada con los
medicamentos de un menor bajo la supervisión y responsabilidad de su padre, madre
o tutor legal.</p>

<p>La App no solicita deliberadamente información personal de menores para fines
publicitarios o comerciales.</p>

<p>Si un padre, madre o tutor considera que un menor ha proporcionado información
personal que debería eliminarse, puede ponerse en contacto con nosotros mediante
el correo indicado en esta política.</p>

<h2>9. Seguridad</h2>

<p>Shell Core Software aplica medidas razonables para proteger la información
gestionada por la App.</p>

<p>Debido a que la información se almacena localmente en el dispositivo, el usuario
también es responsable de mantener protegido su dispositivo mediante las medidas
de seguridad disponibles en el sistema operativo, como bloqueo de pantalla,
contraseña u otros mecanismos de protección.</p>

<h2>10. Eliminación de información</h2>

<p>El usuario puede modificar o eliminar la información registrada utilizando las
funciones disponibles dentro de Doctor Reminder.</p>

<p>También puede eliminar los datos almacenados por la App desde las opciones de
configuración del dispositivo.</p>

<p>Al desinstalar la App, los datos almacenados localmente por Doctor Reminder pueden
eliminarse de acuerdo con el comportamiento del sistema operativo.</p>

<h2>11. Información médica y responsabilidad</h2>

<p>Dr. Reminder es una herramienta de organización y recordatorio. La App no
constituye un servicio médico y no sustituye las indicaciones de un profesional
sanitario.</p>

<p>La App no:</p>

<ul>
  <li>Diagnostica enfermedades.</li>
  <li>Prescribe medicamentos.</li>
  <li>Recomienda tratamientos médicos.</li>
  <li>Determina dosis médicas.</li>
  <li>Sustituye las instrucciones de un médico, farmacéutico u otro profesional sanitario.</li>
</ul>

<p>El usuario debe introducir y utilizar las dosis, horarios y demás indicaciones
conforme a las instrucciones proporcionadas por su profesional de salud.</p>

<p>Los recordatorios dependen de la información introducida por el usuario y de la
configuración y funcionamiento del dispositivo. El usuario debe comprobar siempre
las indicaciones proporcionadas por su profesional sanitario.</p>

<h2>12. Cambios a esta política</h2>

<p>Shell Core Software puede actualizar esta Política de Privacidad cuando sea
necesario debido a cambios en Dr. Reminder, en sus funciones o en los requisitos
legales aplicables.</p>

<p>Los cambios se reflejarán mediante una nueva fecha de "Última actualización" en
esta misma página.</p>

<p>Se recomienda revisar periódicamente esta página para conocer la versión vigente.</p>
