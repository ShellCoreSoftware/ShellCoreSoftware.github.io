<h1>Política de Privacidad</h1>

<p>Esta Política de Privacidad describe cómo <strong>Recordatorio de Medicinas</strong>
("la App") recopila, usa y protege la información de sus usuarios.</p>

<h2>1. Responsable de la aplicación</h2>
<p>[TU NOMBRE O EL DE TU EMPRESA]<br>
Correo de contacto: <a href="mailto:[TU CORREO]">[TU CORREO]</a></p>

<h2>2. Información que recopilamos</h2>

<p><strong>a) Datos que tú ingresas directamente:</strong></p>
<ul>
  <li>Nombre, edad, teléfono (opcional) y correo electrónico (opcional) de la persona registrada en la App</li>
  <li>Nombre de medicamentos, dosis, cantidad disponible, horarios y frecuencia de los recordatorios</li>
</ul>

<p><strong>b) Datos del sensor del dispositivo:</strong></p>
<ul>
  <li>Conteo de pasos diarios, usando el sensor de actividad física del celular (con tu permiso), para mostrar estadísticas de actividad física dentro de la App</li>
</ul>

<p><strong>c) Datos recopilados por publicidad (anuncios):</strong></p>
<p>La App muestra anuncios a través de la red de mediación Unity LevelPlay, la cual puede
trabajar con distintas redes publicitarias asociadas. Estas redes pueden recopilar
automáticamente identificadores de publicidad del dispositivo, información técnica
(modelo, sistema operativo) y datos de interacción con los anuncios, con el fin de mostrar
publicidad relevante y medir su rendimiento.</p>

<h2>3. Dónde se almacenan tus datos</h2>
<p>Toda la información personal y de medicamentos que ingresas (punto 2a) se guarda
<strong>únicamente en la base de datos local de tu propio dispositivo</strong>. La App no
envía estos datos a ningún servidor externo ni los comparte con terceros. Si desinstalas
la App, esta información se elimina de forma permanente.</p>

<h2>4. Uso de la información</h2>
<p>Los datos se usan exclusivamente para:</p>
<ul>
  <li>Permitir el funcionamiento de los recordatorios de medicamentos</li>
  <li>Mostrar el resumen de actividad física</li>
  <li>Mostrar anuncios dentro de la App (a través de Unity LevelPlay)</li>
</ul>

<h2>5. Compartición de datos con terceros</h2>
<p>No compartimos, vendemos ni alquilamos tu información personal (nombre, edad, teléfono,
correo, medicamentos) a ningún tercero. Únicamente el proveedor de anuncios (Unity
LevelPlay y sus redes publicitarias asociadas) puede acceder a los datos técnicos descritos
en el punto 2c, conforme a sus propias políticas de privacidad:
<a href="https://unity.com/es/legal/privacy-policy" target="_blank">unity.com/es/legal/privacy-policy</a></p>

<h2>6. Permisos que solicita la App</h2>
<ul>
  <li><strong>Notificaciones:</strong> para mostrar los recordatorios de medicamentos</li>
  <li><strong>Alarmas exactas:</strong> para que los recordatorios suenen a la hora correcta</li>
  <li><strong>Actividad física / sensor de pasos:</strong> para el conteo de pasos diarios</li>
  <li><strong>Inicio automático</strong> (en algunos fabricantes): para que las alarmas sigan funcionando después de reiniciar el dispositivo</li>
</ul>

<h2>7. Menores de edad</h2>
<p>La App puede usarse para registrar el tratamiento médico de un menor de edad bajo la
supervisión de un adulto responsable (padre, madre o tutor). No recopilamos
intencionalmente información de menores sin dicha supervisión.</p>

<h2>8. Tus derechos</h2>
<ul>
  <li>Puedes editar o eliminar tus datos directamente dentro de la App en cualquier momento</li>
  <li>Desinstalar la App borra toda la base de datos local de forma permanente</li>
</ul>

<h2>9. Cambios a esta política</h2>
<p>Podemos actualizar esta política ocasionalmente. Los cambios se reflejarán con una nueva
fecha de "Última actualización" en esta misma página.</p>
